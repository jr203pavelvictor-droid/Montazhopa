# ALTO 4.0 — QA / review

Основа: `6096a97de9a1581790b7b199b6c2399c4680505b`, Montazhopa 3.2.0-beta.2. Ветка: `feature/alto-4-ui`. Версия пакета: `4.0.0-beta.1`.

## Выполнено локально

- Baseline: прежний ZIP воспроизведён с SHA256 `bc944bcfb2ac28f268f44f61555a8844fc95c658d1f1da239c5fb02388c725b7`; прежние 16 browser checks и JS/Python checks прошли до изменения UI.
- JS синтаксис всех runtime файлов и детерминированная сборка ZIP с проверкой состава, CRC и SHA256.
- Движения: 55 104 сравнений; дополнительно Ease Out — монотонность, симметрия Ease In, концы и маршрут при 23.976/25/29.97/60 fps.
- Host model: 17 сценариев, включая новую проверку записи/чтения Ease Out через JSX.
- 12 проверок нативных кривых, rollback и парных переходов; 9 — захват кадра и безопасная загрузка PNG.
- Bridge, local/update/watcher tests, 155 upstream DSP/sync tests, 5 Python worker tests.
- Дополнительная проверка соответствия оформления: изогнутые хромированные ленты, открытая A, реальные включаемые/выключаемые зелёные switches, локальные шрифты.
- Прежние 16 UI checks с сохранением прежней логики применения; запрос поиска теперь проверяет общие результаты.
- ALTO browser suite: совместимость старых настроек/избранного и файлов, локальные шрифты, общий поиск, pin limit, недавнее, сохранение параметров и маршрута после reload, числовой ввод, отмена сценария, Ease Out UI, клавиатура, RU/EN, прозрачность, неизвестная будущая схема данных.
- Все шесть разделов в RU/EN при 300 / 420 / 600 / 960 px; дополнительно controls и Motion Zoom. Никаких незапрошенных HTTP(S) обращений при локальном использовании.
- Ручной просмотр скриншотов: каталог, узкий режим, Motion Zoom, главная и настройки. Стекло на каждой карточке не запускает backdrop blur.

Тесты Playwright: Chromium 134 headless shell, SwiftShader в изолированной среде. Нативный desktop Chromium здесь не запускается из-за ограничений Unix sockets; это не проверка GPU Premiere.

## Не выполнено в этой среде

- Живые CEP/QE, экспорт кадра и финальный рендер в Premiere на macOS / Windows.
- Производительность/CPU/RAM на реальном GPU и длительная работа с пользовательской библиотекой.
- Запуск нативных установщиков и внешнего updater helper после закрытия Premiere. Состав/проверка/staging/rollback данных проверены на моделях и временных файлах.
- Публикация ALTO 4.0.0-beta.1 разрешена пользователем 19.10.2026; main обновляется после проверок, затем workflow публикует prerelease.

Пользователь отдельно разрешил merge и выпуск после исправления визуала. Это не подтверждает живой прогон Premiere; CI не подменяет такую проверку.
