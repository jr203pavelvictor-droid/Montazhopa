Браузерные тесты используют настоящий Chromium и модель Premiere bridge. Локальные JS/Chromium/файловые проверки прошли. FFmpeg отсутствует в локальном PATH: два Python-теста здесь пропускаются; CI обязательно проверяет FFmpeg/FFprobe и выполняет полный Python-прогон. Повтор локального Python-прогона с расширенным доступом после отказа разрешения не выполнялся.

CI перед merge проверяет весь набор и сборку. Release workflow повторяет проверки перед публикацией. Точные логи доступны в GitHub Actions и PR; наличие опубликованного release asset подтверждает завершённый выпуск.

## Что не подтверждено живым Premiere

Живая проверка beta.2, финального рендера, реального CEP/QE, Gaussian Blur разных версий/локализаций, установки/отката в нативных папках Windows/macOS и GPU-производительности не выполнена. По просьбе пользователя управление Premiere прекращено; живую проверку выполняет он сам. Версия остаётся prerelease.

Readback/rollback проверяются на модели публичных методов. Код проверяет каждый записанный ключ и значение; ошибка восстановления явно возвращается в UI. Успешный возврат QE сам по себе не считается успехом. Это не гарантия поведения недокументированного QE на каждой версии Premiere.

## Поддерживаемые границы

- Цели blur отделены от Adjustment Layer зума. Поддержаны активная секвенция, явно выбранные клипы/подтверждённый отдельный нест объекта, скорость 100%, доступная схема Gaussian RU/EN. Время переводится через In исходника и смещение клипа. Маршрут должен помещаться в каждую цель.
- Общий нест с несколькими объектами не обеспечивает селективность. Привяжите отдельный клип в рабочей композиции или выделенный нест нужного объекта; автоматического обхода вложенных секвенций нет. Time Remapping и изменённая скорость отклоняются до записи.
- Остальные эффекты и Opacity masks не используются для записи blur. Ручное изменение эффекта ALTO блокирует перезапись. При неполном rollback UI сообщает оставшиеся эффекты/клипы.
- Preview показывает геометрию/время маршрута. Отдельные слои нельзя изолировать в полном статичном снимке; фальшивого размытия всей композиции нет.
- Аудиофайл для preview до 64 MB; PCM-отрезок также до 64 MB. Декодер может не поддерживать кодек. Сумма fades не превышает отрезок. Вставка требует тон 1x; reverse поддержан. Громкость preview не записывается в клип.
- Созданный отрезок остаётся в библиотеке и при отказе host-вставки: это сохраняет доступность файла при частичном импорте Premiere. Удаление файла не используется как rollback монтажа.
- Тишина анализируется по одному исходнику. Применение импортирует новую XML-секвенцию с видео/аудио; не выполняет ripple текущей секвенции. Файл, проект и секвенция проверяются перед применением. Полный rollback нативного монтажа не обещается.
- Диагностика читает источники и доступные DOM-связи. Она не оценивает изображение/звук, маски и все возможные повреждения вложенных секвенций; переход к объекту зависит от API.
