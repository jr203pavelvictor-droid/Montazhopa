# Изменения в 3.0 beta 1

Основа: Монтажопа 2.1 и черновик от 17 октября с исправлением плотности ключей.

## Интерфейс

Полностью заменена панель: графитовая основа, серебристые акценты, мягкие края и тени. Карточки приподнимаются без сдвига соседей. Названия видны постоянно; пояснения открываются с задержкой. Поиск скрыт за лупой. Отдельный экран настроек инструмента, возврат в библиотеку к прежнему месту. Русский и английский языки; язык и анимации — в настройках. Виды «плитки/список» и размеры сохраняются для каждого раздела.

## Движение

Вместо библиотеки из повторяющихся направлений — инструменты с параметрами. Появились общий движок и контролируемое упрощение ключей. Движение записывается во времени исходника с учётом In Point и скорости клипа. Ракурсная камера получила компактный экран, точки на карте, отдельный тайминг для перехода к каждой точке и проверку длины маршрута.

## Повторное применение

Эффект запоминается по проекту, секвенции и клипу. Панель требует «Да/Нет» перед заменой. При отказе нет записи параметров. При ошибке записи в существующий собственный эффект выполняется восстановление его снимка. Новые частично добавленные эффекты удаляются, если API позволяет подтвердить их принадлежность. Ручные изменения не перезаписываются автоматически.

## Из сегодняшнего разбора проектов

- Библиотека медиа и редактируемых монтажных фрагментов, собственные варианты движения, теги, избранное, MOGRT и аудиопрослушивание.
- Механизм мини-проекта вместо пересказа эффектов и ключей. Для этой версии выбрана вставка вложенной секвенцией без Windows-only DLL.
- Поиск установленных видеоэффектов Premiere с проверкой применения к выбранным клипам.
- Наблюдаемые папки и импорт после завершения копирования файлов.
- Локальные инструменты BPM/тишины с добавлением маркеров после просмотра.
- Пользовательские сценарии из нескольких последовательных операций.
- Версии и пакеты обновления: SHA-256, ZIP-проверки, staging и резервная копия. Сеть выключена по умолчанию.

## За пределами beta 1

Не включены сторонние бинарники, AI-движки, нативные аналоги всех 93 модулей Film Impact и автоматическое удаление дублей/тишины. В разделе сторонних плагинов оставлен согласованный анонс. Статус и ограничения описаны в `IMPLEMENTATION.md` и `START_HERE_RU.md`.
