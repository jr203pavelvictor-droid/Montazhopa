# ALTO 4.0.0-beta.3

**Hotfix загрузки JSX.** В beta.2 общий модуль содержал обращение o.in и ключ объекта in без кавычек: этот синтаксис не проходит строгий ES3-разбор ExtendScript. Доступ заменён на скобочный с кавычками; CEP теперь загружает тот же собранный host.bundle.jsx, который проверяется и вызывается bridge. Перед сборкой ZIP весь bundle обязательно проходит ES3-парсер; bridge-тест проверяет также фактически отправляемый bootstrap. Прежний прогон в современном Node эту несовместимость не выявлял. Это устранение воспроизведённого дефекта синтаксиса, а не заявление о живой проверке Premiere.

Утверждённый интерфейс из design-preview перенесён в рабочую панель: серебристый трёхслойный знак, локальный Montserrat RU/EN, полупрозрачное стекло и плавающая навигация. Прежние разделы доступны через «⋯» в шапке.

- **Motion Zoom:** независимые длительность и режим каждого перелёта, включая Ease In / Ease Out; Elastic-параметры только для Elastic; паузы точек. Перетаскивание в кадре, перестановка маршрута, дублирование и доступные кнопки. В шапке — подключение Adjustment Layer, под кадром — захват таймлайна, над навигацией — применение.
- **Селективный расфокус:** отдельная привязка одного/нескольких клипов или явно подтверждённых отдельных нестов объекта. У каждой точки — сила, начало и длительность нарастания/возврата. Пересечения используют максимальную огибающую. Gaussian Blur и параметр силы определяются по фактическому списку и схеме эффекта RU/EN; ключи читаются обратно, собственный эффект используется повторно.
- **Звук:** реальный waveform всех каналов, In/Out мышью или числами, прослушивание отрезка, громкость preview и fades. Вставляется новый PCM WAV; исходный файл и ProjectItem In/Out не меняются. Есть прогресс, отмена подготовки и проверка вставленного клипа.
- **Проверка проекта:** чтение offline-медиа, недоступных путей и доступных связей клипов. Результаты с путём/расположением, обновлением и переходом, если API его поддерживает. Автоисправлений нет.
- **Тишина:** отдельные отступы до/после речи, карта и список интервалов, прослушивание участка/границ, исключения и итог удаления. Применение создаёт новую XML-секвенцию из одного исходника, сохраняя текущий монтаж.

**Установка:** скачайте Montazhopa_4.0.0-beta.3.zip из assets этого релиза. Либо в ALTO: Настройки → разрешить интернет и тестовые версии → Проверить → подготовить обновление. Технический ID, данные, имя ZIP, SHA-256 и прежний откат сохранены. Архивы Source code не являются установочным пакетом.

**Предварительный релиз. Живая проверка beta.3 в Premiere не выполнялась; по просьбе пользователя её выполняет он сам.** Автоматические проверки покрывают настоящий HTML/CSS/Web Audio в Chromium, общую модель анимации, JSX-контракты, readback/rollback на модели API и пакет обновления. Конкретные CEP/QE, Gaussian Blur, рендер и нативная установка/откат Windows/macOS ещё требуют живого подтверждения.

Границы: расфокус — явно отделённые клипы либо отдельный нест только нужного объекта в активной секвенции, скорость 100% и полное покрытие маршрута. Общий нест размоется целиком; автоматического поиска/раскрытия объектов внутри него нет. Неподдерживаемые схемы эффекта и скорости отклоняются. Preview маршрута не имитирует селективное размытие полного снимка. Аудиоотрезок ограничен 64 MB PCM WAV и тоном 1x; изменённый тон можно предварительно экспортировать существующей кнопкой WAV. Тишина требует Python/FFmpeg/FFprobe, waveform — доступного Web Audio декодера.
