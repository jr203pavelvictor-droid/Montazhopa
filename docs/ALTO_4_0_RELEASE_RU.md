# ALTO 4.0 / Liquid Graphite

Монтажопа стала ALTO. Дизайн переработан по присланным референсам iOS и логотипа ALTO.

- Три изогнутые хромированные ленты вместо прямых шевронов; открытая A и серебристая надпись ALTO.
- Полупрозрачное графитовое стекло, световые кромки, круглые кнопки, синие действия и зелёные переключатели.
- Локальный Montserrat RU/EN, адаптация панели 300–960 px, отключаемая прозрачность.
- Главная, общий поиск, избранное и закреплённые команды, недавнее, сохранение параметров и контекста.
- Motion Zoom: Ease Out вместе с существующими режимами, числовые значения и кадр с таймлайна.

Прежние инструменты, настройки, пресеты, библиотека, папки наблюдения, ownership и откат сохранены. Выборочный расфокус одного/нескольких слоёв остаётся следующим этапом.

**Установка:** скачай `Montazhopa_4.0.0-beta.1.zip` ниже или открой установленную панель → Настройки → разреши интернет и beta → Проверить. Историческое имя ZIP и технический ID сохранены для совместимости обновлятора. Архивы Source code для обновлятора не подходят.
