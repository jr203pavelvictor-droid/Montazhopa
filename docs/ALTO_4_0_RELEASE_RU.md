# ALTO 4.0.0-beta.5 — 20 октября 2026

## Исправление обновления на macOS и пути установки

- Проверяется ExtensionBundleId фактически запущенной панели, а не точное имя папки. Поддерживаются переименованные каталоги, пробелы, Unicode, file URL и percent-encoding; существующий буквальный % в имени не декодируется повторно. Приоритет — URL запущенного index.html, затем путь CEP. Чужая или несуществующая папка отклоняется до изменений.
- Общий определитель пути используется обновлятором, JSX bridge, локальным worker и диагностикой. В диагностике показывается фактическая папка панели. Отсутствие прав записи получает понятное сообщение.
- Новые резервные копии установщиков и встроенного обновлятора находятся в Montazhopa3/installation-backups, вне Adobe/CEP/extensions. Откат также понимает прежние .previous-копии.
- Установщик macOS сохраняет все пользовательские копии с ID com.victor.motionviewer (включая переименованные и .previous) вне CEP, устанавливает одну каноническую панель и восстанавливает прежние папки при сбое. Чужие расширения и личные данные сохраняются. Обнаруженная системная копия в /Library выводится с путём; установщик не меняет её и не повышает права.
- Исправление пустого интерфейса beta.4 включено: браузерный AltoAudio регистрируется и при наличии CommonJS globals. Ранняя диагностика запуска и прежнее исправление ES3 JSX сохранены.

**Переход с 3.2.0-beta.2 при Extension path does not match bundle:** старый updater блокирует обновление до чтения нового кода; исправление на GitHub не переписывает его автоматически. Закройте Premiere, распакуйте полный ZIP и один раз запустите INSTALL_MAC.command (при отсутствии execute permission: bash и перетаскивание файла в Terminal). Администратор не нужен для пользовательской установки; если найдена системная копия, потребуется её отдельно отключить с администратором. Затем откройте ALTO. Папка: ~/Library/Application Support/Adobe/CEP/extensions/com.victor.motionviewer.

**Проверки:** регрессии путей и staging/rollback на реальной временной файловой системе; выполнение shell-логики Mac-установщика в изолированном HOME с подменой ditto/defaults/pgrep; миграция дубликатов, восстановление после ошибки, отказ по SHA-256 и системной копии. Это не живое тестирование macOS/Premiere. Публичный выпуск предварительный.
