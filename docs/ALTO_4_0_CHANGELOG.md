# ALTO 4.0.0-beta.5 — 20 октября 2026

## Исправление обновления на macOS и пути установки

- Проверяется ExtensionBundleId фактически запущенной панели, а не точное имя папки. Поддерживаются переименованные каталоги, пробелы, Unicode, file URL и percent-encoding; существующий буквальный % в имени не декодируется повторно. Приоритет — URL запущенного index.html, затем путь CEP. Чужая или несуществующая папка отклоняется до изменений.
- Общий определитель пути используется обновлятором, JSX bridge, локальным worker и диагностикой. В диагностике показывается фактическая папка панели. Отсутствие прав записи получает понятное сообщение.
- Новые резервные копии установщиков и встроенного обновлятора находятся в Montazhopa3/installation-backups, вне Adobe/CEP/extensions. Откат также понимает прежние .previous-копии.
- Установщик macOS сохраняет все пользовательские копии с ID com.victor.motionviewer (включая переименованные и .previous) вне CEP, устанавливает одну каноническую панель и восстанавливает прежние папки при сбое. Чужие расширения и личные данные сохраняются. Обнаруженная системная копия в /Library выводится с путём; установщик не меняет её и не повышает права.
- Исправление пустого интерфейса beta.4 включено: браузерный AltoAudio регистрируется и при наличии CommonJS globals. Ранняя диагностика запуска и прежнее исправление ES3 JSX сохранены.

**Переход с 3.2.0-beta.2 при Extension path does not match bundle:** старый updater блокирует обновление до чтения нового кода; исправление на GitHub не переписывает его автоматически. Закройте Premiere, распакуйте полный ZIP и один раз запустите INSTALL_MAC.command (при отсутствии execute permission: bash и перетаскивание файла в Terminal). Администратор не нужен для пользовательской установки; если найдена системная копия, потребуется её отдельно отключить с администратором. Затем откройте ALTO. Папка: ~/Library/Application Support/Adobe/CEP/extensions/com.victor.motionviewer.

**Проверки:** регрессии путей и staging/rollback на реальной временной файловой системе; выполнение shell-логики Mac-установщика в изолированном HOME с подменой ditto/defaults/pgrep; миграция дубликатов, восстановление после ошибки, отказ по SHA-256 и системной копии. Это не живое тестирование macOS/Premiere. Публичный выпуск предварительный.

# ALTO 4.0.0-beta.4 — 20 октября 2026

## Исправление пустой панели в CEP

- Воспроизведена ошибка JavaScript до первого render(): `ui/audio-range.js` возвращался после CommonJS-экспорта в CEP `--mixed-context`, поэтому `window.AltoAudio` отсутствовал и `MZPlus.init()` падал при обращении к `init`. Обычный браузер без Node-глобальных объектов эту ветку не исполнял.
- Экспорт Node-энкодера теперь сосуществует с регистрацией браузерного API. В чистом Node DOM по-прежнему не требуется. JSX-исправление beta.3 сохранено.
- До остальных скриптов загружается независимый обработчик ошибок: первая ошибка, отсутствующий скрипт или незавершённая инициализация отображаются в панели. Сообщение не отправляется в сеть и не записывает пользовательские данные.
- Добавлены регрессии browser / CEP mixed-context / Node, проверка синтаксиса всех renderer-скриптов по ES2019 и тесты ранней диагностики. Production UI теперь также запускается с видимыми CommonJS-глобальными объектами.
- Изменения ограничены запуском, диагностикой и тестами. Дизайн, функции и пользовательские форматы не менялись.

Живой Premiere в среде разработки недоступен. Mixed-context воспроизведён в VM и Chromium; это не проверка всех особенностей нативного CEP/QE.

# ALTO 4.0.0-beta.2 — 2026-10-20

- Утверждённый design-preview перенесён в настоящую панель: стекло, Montserrat, плавающая навигация и все прежние разделы.

# ALTO 4.0.0-beta.1 — 19 октября 2026

Публикация и объединение с main разрешены пользователем после повторной сверки референсов.

## Визуальная корректировка по двум референсам

- Прямые тонкие шевроны заменены тремя изогнутыми хромированными лентами, как в присланном логотипе. Надпись ALTO с открытой A; знак увеличен в шапке. SVG, lockup и app icons обновлены из одной геометрии.
- Плоская почти чёрная тема заменена полупрозрачным графитовым стеклом с холодными отражениями, бликами, освещённой кромкой и глубиной.
- Синие основные действия, зелёные переключатели, круглые кнопки и стеклянные сегменты приближены к iOS-референсу. Ползунки показывают заполнение; реальные значения и доступность сохранены.
- Нативные команды Premiere не менялись в этом визуальном проходе.

## Реализовано

- Имя ALTO в панели и меню CEP; три серебристых уровня A, SVG + app icons, локальный Montserrat RU/EN.
- Графитовое стекло в духе iOS: новая шапка, плавающая навигация, группировка форм, карточки, модальные окна, поля и состояния.
- Главная с быстрыми переходами, избранным и недавно открытыми командами/пресетами. До восьми закреплённых команд; прежнее избранное пресетов и материалов сохранено.
- Прямые разделы: Главная, Движение, Медиатека, Звук, Инструменты и существующие сценарии. Внутри Движения сохранены Анимация / Переходы / Эффекты / Motion Zoom.
- Поиск RU/EN сразу по всем этим сущностям, включая теги локальных материалов и собственные варианты; фильтры по типу. Установленные эффекты Premiere ищутся прежним отдельным инструментом, без выдуманного общего индекса.
- Cmd/Ctrl+K, прежние Cmd/Ctrl+F и `/`, Escape. Поиск закрывается при явном переходе в раздел; устаревшие подсказки не зависают над новым экраном.
- Сохранение последнего раздела, категории, прокрутки, фильтра, параметров движения и маршрута Motion Zoom. Привязку к слою и снимок кадра нужно подключить снова после перезапуска.
- Числовой ввод рядом с ползунками, проверка границ, единицы; существующий reset сохранён. Motion Zoom: паузы видны в списке точек, доступные кнопки перестановки/удаления, Elastic-параметры видны только в соответствующем режиме.
- Motion Zoom Ease Out добавлен и в предпросмотр, и в JSX; математически проверено замедление к цели. Существующие режимы сохранены.
- Сценарии можно открыть для проверки списка шагов перед запуском; исполнение использует прежний backend.
- Настройки сгруппированы с быстрыми переходами, включают отключение прозрачности. Подписи мини-плеера RU/EN; смена рабочего контекста останавливает плеер, скрытие панели приостанавливает звук.
- Компактные строки на ширине 300–399 px; на самой узкой панели навигация показывает иконки с подсказками. На широкой — грид и инспектор рядом с превью.

## Сохранено

Все прежние команды и экраны остаются доступны: ключи/ownership/rollback, восемь направлений, защита краёв, три парных перехода, импорт/экспорт пресетов, Motion Zoom и кадр таймлайна, библиотека/фрагменты/MOGRT, аудио и WAV-export, анализ ритма, тишина/субтитры/повторы/синхронизация, .prfpset search, watch folders, сценарии, диагностика, обновление из ZIP/GitHub и откат.

Совместимость: `com.victor.motionviewer`, `Montazhopa3`, `mz3.preferences`, имена JSON, существующие Project bins, форматы `montazhopa-presets` / `montazhopa-update`, GitHub repository и имя ZIP сохранены. Новый `alto-workspace.json` (в browser demo — `alto4.workspace`) не переписывает пользовательскую библиотеку. Неизвестная будущая схема контекста не перезаписывается.

## Обязательная следующая разработка

**Расфокус одного ИЛИ НЕСКОЛЬКИХ выбранных слоёв/нестов в Motion Zoom. Множественный выбор обязателен.** Плавное появление/снятие размытия синхронно с зумом; сила, начало и длительность, сохранение существующих масок; остальные слои резкие. Нужен отдельный feasibility spike по установленным blur-эффектам, маскам, времени вложенных секвенций и проверке/откату ключей. В этой сборке готового селективного blur нет, кнопка-заглушка не добавлена.

Полная UXP-миграция, AI, face/object tracking, drag-and-drop на timeline, новый медиабраузер с relink/видеопревью, расширенная waveform-система и структурный Project Health остаются отдельными этапами плана. Существующие механики этих экранов не выдаются за новые возможности.
