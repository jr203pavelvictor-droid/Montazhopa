# Проверка beta 1

Выполнены:

- Синтаксическая проверка JavaScript и объединённого ExtendScript.
- 62 192 сравнения значений общей модели и сокращённой кривой на частотах 23.976, 25, 29.97 и 60 fps. Максимальное отклонение для процентных/угловых параметров меньше 0.025; для нормализованной позиции — меньше 0.000081.
- Линейное Photo Motion: два ключа масштаба. Линейный двухточечный маршрут с паузами: четыре точки.
- 16 контрактных проверок имитированного API Premiere: выделение, время исходника, скорость, ключи OUT, сохранение чужих эффектов, запрос подтверждения, замена без накопления, восстановление после ошибки, сохранение учёта после сброса сессии, безопасный JSON.
- 7 проверок локальных сервисов: сохранение данных, корректные WAV, сравнение версий, отсутствие сетевого запроса при выключенных обновлениях, стабильный импорт новых файлов, ZIP staging, отклонение обхода пути/повреждённого/неполного/старого пакета.
- 12 сценариев UI в Chromium с имитацией Premiere: поиск RU/EN, параметры, применение, «Нет»/«Да», свой вариант, переключение языка, независимые настройки анимации и предпросмотра, ракурсная камера, синтетический звук и ширины панели 300–960 px.
- При запуске и локальном использовании панели не было запросов HTTP(S) и ошибок JavaScript/CSP.

В комплекте `preview-catalog.png` и `preview-detail.png` — снимки настоящего интерфейса, а не нарисованные макеты.

Не выполнены: установка и запуск в настоящем Premiere на Windows/macOS; живой рендер и экспорт; проверка QE API конкретных версий; исполнение OS-помощников обновления; опубликованный GitHub-релиз. Поэтому статус сборки — beta 1.
