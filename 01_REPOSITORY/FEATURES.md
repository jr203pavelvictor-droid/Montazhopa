# Состав 3.1.0-beta.1

| Функция | Реализация и границы |
| --- | --- |
| Стеклянный интерфейс | Сохранены разделы и логика 3.0. Добавлены blur, светлые грани, контрастные поверхности и навигация. Для старого CEP остаётся оформление градиентами |
| Движение, камера, варианты, библиотека | Сохранены из 3.0 beta 1. Это собственный код Монтажопы, не порт Film Impact |
| Waveform, pitch/reverse preview | Адаптированный реальный audioPreview.js VibeTools + Jungle. Без случайного waveform при ошибке. Изменённый WAV создаётся отдельно через FFmpeg; требуется rubberband для pitch |
| Монтажные фрагменты | Существующий JSX-механизм Монтажопы сохраняет диапазон выделения со всеми попавшими слоями. Он не равнозначен точному копированию только выбранных клипов через нативный VibeTools DLL. Исходные медиа остаются внешними |
| Эффекты Premiere | Существующий механизм Монтажопы с сопоставлением QE по времени. Опасный index fallback IronFX не перенесён |
| Файлы .prfpset | Собственный XML-индексатор по результатам разбора IronFX. Поиск имён и открытие папки файла. Импорт/применение через стандартную панель Effects |
| Watch folders | Собственный рекурсивный механизм по результатам разбора SheepDog: стабильность записи, ACK импорта, повтор ошибок, подпапки в Project, дедупликация, история для каждого сохранённого проекта |
| Нарезка тишины | Оригинальный OpenCutz silence.py и premiere.py. Анализ одного исходника, просмотр/выбор интервалов, новая XML-секвенция. Python/FFmpeg/FFprobe устанавливаются отдельно. Дорожки уже смонтированной секвенции не анализируются |
| Субтитры | Оригинальный OpenCutz captions.py с адаптером локального CPU faster-whisper. RU/RO/EN/auto, правка текста, SRT и импорт в Project. AI-движок и модель устанавливаются отдельно |
| Повторы | Оригинальный repeat_detect.py. Эвристика похожих фраз, не оценка качества дублей и не автоматическое удаление |
| Синхронизация | Оригинальный Syncitol dsp.js. Два аудиофайла, первые 120s, ±30s, оценка надёжности, показ сдвига. Перемещение клипов вручную, декодирование через Web Audio |
| Обновление | Адаптированный PR Extension клиент релизов + собственный установщик Монтажопы. Публичный GitHub, beta-channel, точное имя asset, ZIP и SHA-256, staging, backup/rollback после закрытия Premiere. Опциональная сверка digest GitHub. Не криптографическая подпись автора |
| Публикация | Готовый ZIP релиза, исходники репозитория, build script и GitHub Actions |

## Не включено

- Нативный importer/control surface VibeTools: требует Adobe SDK и отдельной сборки для каждой ОС.
- Нативный UXP addon и полная панель Syncitol: это другая система расширений.
- SmartCut и Genius Installer Manager: не найдено явное разрешение на заимствование собственного кода этих отдельных продуктов.
- Полная копия OpenCutz с его сервером, всеми AI-функциями и интерфейсами.
- Нативные переходы Film Impact и обещание полного функционального равенства с коммерческим плагином.

## Проверка

Подробный результат проверок после сборки хранится в VALIDATION.md. Проверка исходников/моделей и работа внутри настоящего Premiere — разные уровни. Эта beta не имеет подтверждённой совместимости каждого host-действия со всеми версиями Premiere 2020–2026.
