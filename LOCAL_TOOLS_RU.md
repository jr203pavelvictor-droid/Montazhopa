# Локальная нарезка и субтитры

Основная панель, движение, библиотека, плеер, поиск эффектов, watcher и обновления не требуют Python. Для OpenCutz-нарезки нужны **Python 3.11+**, **FFmpeg** и **FFprobe**. Для распознавания дополнительно устанавливаются faster-whisper и модель. Готовые сторонние EXE/DLL, FFmpeg и модели в этот архив не включены.

## Подключить уже установленные инструменты

1. Установи Python 3.11+ с https://www.python.org/downloads/, если его ещё нет.
2. Источник FFmpeg и ссылки на сборки под ОС: https://ffmpeg.org/download.html . Нужны обе программы `ffmpeg` и `ffprobe`. Распакуй в папку, которую не будешь переносить.
3. В панели открой **Инструменты → Локальная обработка**. Укажи полный путь к `python.exe` / `python3`, `ffmpeg.exe` / `ffmpeg`, `ffprobe.exe` / `ffprobe`. Вставляй путь без внешних кавычек. При пустом поле используется PATH, а для Python также проверяется пользовательский runtime Монтажопы.
4. Нажми **Проверить готовность**. В результате у ffmpeg и ffprobe должно быть `ok: true`. Это выполняет локальные команды проверки версии; ничего не загружает.

Файлы SETUP_LOCAL_TOOLS просто записывают обнаруженный Python в настройки. Они **не устанавливают FFmpeg и не включают AI автоматически**.

## Включить локальные субтитры

Открой терминал в распакованной папке релиза, где находятся `tools` и установщики. Выполни:

Windows:
```powershell
py -3 tools/setup_local.py --ai --model small
```

macOS:
```bash
python3 tools/setup_local.py --ai --model small
```

Это явная команда скачивания: она создаёт отдельное окружение Python в пользовательской папке Montazhopa3, устанавливает `faster-whisper==1.2.1` и скачивает `Systran/faster-whisper-small` с Hugging Face. Исходное видео туда не отправляется. Размер загрузки зависит от платформы и модели; `small` требует заметного места и времени, `base` или `tiny` легче. Повышение размера модели обычно замедляет CPU-распознавание.

После окончания в **Локальной обработке** проверь Python и путь модели. Затем открой **Субтитры и повторы**, выбери файл и RU/RO/EN или Auto. Распознавание этой сборки настроено на CPU и работает с локальным каталогом модели. Во время распознавания запрещены сетевой поиск модели, очистка кеша автора и автоматическая повторная загрузка модели.

Результат нужно вычитать: отредактируй текст, экспортируй SRT, импортируй его в Project и перетащи в секвенцию. Экспорт SRT поддерживает исходные таймкоды файла; если файл на таймлайне обрезан или сдвинут, субтитры тоже нужно совместить.

Распознавание настоящей речи и установка AI-зависимостей в тестовой среде этой сборки не выполнялись. Подключение исходного модуля и экспорт результатов проверены отдельно; реальное качество зависит от модели, шума и языка.
