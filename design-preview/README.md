# ALTO 4.0 — визуальный прототип

Один вариант интерфейса по пользовательским референсам. Это отдельный HTML/CSS/JavaScript-прототип: расширение и его рабочие файлы не подключаются и не изменяются.

## Открыть

Дважды нажмите **review.html**. На странице можно выбрать экран, размер панели и режим «12 скриншотов».

Для панели без внешней страницы откройте **index.html**. Работает напрямую с диска в Chrome / Edge; установка зависимостей и интернет не нужны.

Необязательный сервер из корня репозитория:

```powershell
node design-preview/server.cjs
```

Страница просмотра: <http://127.0.0.1:4174/review.html>. Остановка сервера: Ctrl+C.

## Четыре экрана

- `index.html#home` — бренд, быстрые инструменты, избранное.
- `index.html#catalog` — 9 существующих анимаций, 3 перехода и Drop Shadow; поиск RU/EN, категории, сетка/список, звёздочки, превью и настройка эффекта.
- `index.html#zoom` — кнопка «Подключить выделенный слой» и статус подключения Adjustment Layer, карта кадра, перетаскивание точек, маршрут, проигрывание, масштаб, характер, время перелёта и дополнительные параметры.
- `index.html#settings` — язык RU/EN, предпросмотр, анимации, прозрачность, громкость, данные, обновления и локальные инструменты.

Навигация — нижняя плавающая панель. Поиск — кнопка в шапке или Ctrl/Cmd+K. Escape закрывает диалог. У точек Motion Zoom есть управление стрелками; Shift увеличивает шаг. Можно загрузить свой кадр кнопкой в правом верхнем углу предпросмотра.

Стекло использует настоящий `backdrop-filter`, прозрачные слои, светлые кромки и отражения. Montserrat 400/500/600/700 и серебристый трёхслойный знак скопированы из существующих локальных ресурсов ALTO. Поддерживаются reduced motion, отключение прозрачности и доступный фокус. Настройки прототипа сохраняются только в `localStorage["alto.design.preview.v1"]`.

## Настоящие скриншоты

В `screenshots/` находятся 12 исходных PNG, снятых Chromium с deviceScaleFactor=1: четыре экрана × 420×800 / 320×700 / 600×850. `overview-*.png` объединяют четыре исходных скриншота каждого размера на одном листе. Скриншоты не созданы ImageGen.

Повторить захват:

```powershell
node design-preview/capture.cjs
```

Нужны Playwright и Chrome. Скрипт использует установленный в этой среде runtime; другой модуль можно задать через `ALTO_PLAYWRIGHT_MODULE`, браузер через `ALTO_BROWSER`. Захват по умолчанию открывает локальный HTML через `file:`. Результаты проверки — `screenshots/verification.json`.

## Основание функций и границы

Изучены `com.victor.motionviewer/index.html`, `app.js`, `catalog.js`, `ui/workspace.js`, `integrations.js`, `FEATURES.md` и существующие визуальные превью.

Названия эффектов взяты из `catalog.js`. Настройки Motion Zoom соответствуют `renderCamera()` в `app.js`: масштаб 100–500%, Smooth/Elastic/Snap/Linear/Ease In/Ease Out, время перелёта 0.08–3 с, пауза, защита краёв, подгонка в длину слоя, Motion Blur. Существующая громкость аудиоплеера показана в секции предпрослушивания. Быстрые инструменты — Motion Zoom, «Убрать тишину», «Субтитры и повторы», «Синхронизация звука».

Прототип проигрывает схему маршрута, а не рендер Premiere. `assets/landscape.svg` — локальная демонстрационная векторная сцена для разметки, не кадр из пользовательского проекта. Интерфейс не выдает её за захваченный кадр. Подключение Premiere, захват таймлайна, применение анимаций, обновления и локальная обработка показывают пояснения; не выполняют внешние действия. Пресеты, медиатека и настройки расширения не читаются.

Это сохранённый самостоятельный прототип этапа согласования. После отдельного разрешения пользователя его оформление перенесено в рабочую панель beta.2; актуальные функции и ограничения описаны в `../docs/ALTO_4_0_WORKFLOW_RU.md`. Сам прототип по-прежнему не управляет Premiere.
