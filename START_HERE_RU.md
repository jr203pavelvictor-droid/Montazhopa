# ALTO 4.0.0-beta.5

При ошибке старого обновлятора `Extension path does not match bundle` закрой Premiere и один раз установи полный ZIP через INSTALL_MAC.command. Новая панель находится в пользовательской папке CEP; прежние копии сохраняются вне CEP.

Панель в меню Premiere называется **ALTO**. Новый логотип и стеклянный интерфейс сделаны по двум референсам пользователя. [Изменения](docs/ALTO_4_0_CHANGELOG.md) · [Проверки](docs/ALTO_4_0_QA.md).

Обновление из Монтажопы: Настройки → включить интернет и получение beta → Проверить → Загрузить и подготовить → Установить после закрытия Premiere. Затем закрыть Premiere и открыть его после установки. Старые данные и технический ID сохранены. Для установки вручную используй ZIP из Releases с установщиками, а не Source code.

Новые функции и порядок работы: [Motion Zoom, расфокус, аудиоотрезки, диагностика и тишина](docs/ALTO_4_0_WORKFLOW_RU.md). Живую проверку beta.3 в Premiere выполняет пользователь; автоматические тесты Chromium/модели API её не заменяют. Ниже сохранены исторические инструкции существующих инструментов.

# Захват кадра в Motion Zoom — beta 2

1. Остановить воспроизведение и поставить курсор на нужный общий кадр секвенции.
2. Открыть Motion Zoom и нажать «Взять кадр с таймлайна» под окном предпросмотра.
3. После загрузки изображения расставить точки маршрута. Ещё одно нажатие обновляет снимок под курсором.

Это снимок Program Monitor со всеми видимыми эффектами, а не непрерывное видео. Для разметки нужен общий план без уже применённого зума. Кнопка не перемещает курсор, не меняет эффекты, In/Out или видимость дорожек.

Предыдущий ориентир сохраняется при ошибке. Если данная версия Premiere не предоставляет рабочий QE-экспорт кадра, в диагностике будет причина; ручная загрузка изображения остаётся доступной. PNG проверяется по заголовку, размерам и декодированию браузером. Проверки на моделях и в браузере не заменяют проверку экспорта в настоящем Premiere.

Изображение обрабатывается локально, после загрузки временный файл удаляется. Версия для обновления: **3.2.0-beta.2**.

# Монтажопа 3.2.0-beta.1 — первая итерация

## Что изменилось

- У «Перемещения» — два нативных ключа Position, без облака линейных точек и без скрытого fade. Smooth назначает Bezier (тип 5), Linear оставляет равномерное движение.
- Перед успешным завершением читаются все записанные ключи. Для Smooth дополнительно читается реальная кривая между ключами; если Premiere оставил линейное движение или дал выброс, действие откатывается.
- Восемь направлений: влево, вправо, вверх, вниз и четыре диагонали. Градусы остались только у тени.
- «Защитить от чёрных полос» включено по умолчанию для Move, Photo Motion, Slide Cut и Zoom Cut. Размер источника, положение и масштаб Motion участвуют в расчёте; для обычного Move увеличение постоянно и не создаёт ключей Scale.
- Покрытие проверяется по прочитанным значениям Premiere на каждом кадре и полукадре участка. Защита выключает Motion Blur, чтобы размытие не размывало край наружу.
- Убрана категория «Все», первой открывается «Анимация». «Стиль» заменён на «Эффекты», настройки тени сохранены. «Камера» названа «Ракурсный зум / Motion Zoom».
- Добавлены Slide Cut, Zoom Cut и Dip to Black в отдельной категории «Переходы».
- Новый минималистичный SVG объединяет парные округлые формы, плейхед и стык таймлайна. Надпись без стеклянной плашки; стекло на карточках и оболочке сохранено.
- В превью вместо «ХОП» используется MOVE. Фото/видео и переходы показываются на изображении.
- Звуковые карточки проигрывают до 6 секунд при наведении. Выход с карточки, другой звук, клик, уход из панели или скрытие окна останавливают и сбрасывают предпрослушивание. Общая настройка hover учитывается.
- В категориях анимаций, эффектов и переходов доступен импорт собственных JSON-пресетов Монтажопы с проверкой категории. Это не импорт произвольных эффектов .prfpset. Свои медиа добавляются через «Моё» и «Звуки».
- Сохранено исправление beta 2: команды JSX собираются в один файл и загружаются по абсолютному пути, с проверкой версии и читаемой диагностикой.

## Как применять парный переход

1. Выделить **два соседних видеоклипа на одной дорожке** без промежутка и наложения.
2. Открыть «Движение → Переходы» и выбрать переход.
3. Настроить общую длительность, направление и силу. Общая длительность делится пополам: OUT перед стыком и IN после него, с округлением до целого кадра.
4. Нажать «Применить на стыке». При замене существующего эффекта потребуется обычное «Да / Нет».

Оба клипа предварительно проверяются. При ошибке изменения откатываются на обоих. Многоклипная замена между разными типами эффектов (например, Shadow → Transform) остановится до записи: сначала нужно убрать старую тень.

Это **парные анимации**, а не нативный переход Premiere с областью перекрытия и смешиванием кадров. Slide/Zoom меняют движение по обе стороны склейки. Dip уменьшает прозрачность; если снизу есть видео, оно проявится вместо чёрного. Нативные QE-переходы не вызываются. Аналоги всей библиотеки Film Impact этой итерацией не заявлены.

## Границы защиты краёв

Модель рассчитана на непрозрачный прямоугольник со статичным Motion, центрированным Anchor Point, без вращения и с квадратным пикселем. Она заполняет кадровое окно увеличением с небольшим запасом. Для портретного исходника в горизонтальной секвенции увеличение может быть заметным — это неизбежное кадрирование.

- Неизвестные размеры исходника, анимированный Motion, поворот, смещённый anchor, известный Crop или дополнительный Transform останавливают действие с объяснением.
- Прозрачные области PNG/MOGRT, маски, искажения и другие сторонние эффекты не анализируются по пикселям. Защита прямоугольных границ не закрывает отверстия в альфе.
- Автоматический Scale to Frame Size и эффекты на master clip могут менять эффективную геометрию. Для сложной композиции предпочтителен **Adjustment Layer размером секвенции** над всей композицией; реальный результат обязательно проверяется в Program Monitor.
- Вычисление геометрии источника опирается на поле Premiere `Column.Intrinsic.VideoInfo`, а не на выдуманные свойства `clip.width`.
- Если подходит анимация отдельного прозрачного объекта, защиту можно отключить.

## Ограничения Bezier и восстановления

`setInterpolationTypeAtKey(time, 5, true)` поддерживается. Публичного CEP-вызова для управления скоростью/влиянием ручек и чтения их состояния нет; код это явно помечает. Не используется After Effects API `setTemporalEaseAtKey`.

Проверяется фактическая интерполяция через `getValueAtTime`, а не только код возврата setter. На версии Premiere, которая не подтверждает плавность, Smooth остановится с откатом; Linear остаётся доступным без обещания плавного старта.

Тип интерполяции вновь созданных эффектов сохраняется в записи принадлежности и используется при откате. Старые записи beta 1/2, где тип не сохранялся, трактуются как прежние линейные ключи. Ручные изменения Bezier-ручек старых эффектов нельзя точно восстановить через этот API. Если ошибка отката всё же возникнет, панель показывает её сразу и просит вернуться к сохранённой копии.

## Что остаётся в плане

Трекинг лица/объекта, 3D-инструменты, автоматическое MOGRT-превью, настоящий перенос медиа из CEP прямо на таймлайн и полная библиотека Film Impact не добавлены. Для них нужны отдельные реализации и проверки. Кнопка «Вставить» и импорт в Project не называются drag-and-drop. Импорт медиа использует публичный `app.project.importFiles`, а не выдуманный QE-import.

# Монтажопа 3.1.0-beta.1 — установка и первое обновление

Это тестовая CEP-сборка с реальным переносом модулей VibeTools, OpenCutz, Syncitol и PR Extension. Рендер и действия внутри Premiere на Windows/macOS здесь не запускались. Перед первым применением проверь её на копии рабочего проекта.

## Если у тебя установлена 3.0.0-beta.1

Можно обновиться существующей кнопкой. Сначала опубликуй ZIP в GitHub Releases по инструкции GITHUB_RU.md. Затем в Монтажопе открой настройки, укажи `ТВОЙ_ЛОГИН/ИМЯ_РЕПОЗИТОРИЯ`, разреши интернет и нажми «Проверить». Скачай и подготовь 3.1.0-beta.1, нажми «Установить после закрытия Premiere», полностью закрой Premiere. После завершения замены открой его снова.

Если интернет-путь пока не сработал, используй «Обновить из ZIP» и выбери **сам ZIP релиза**, без распаковки. После подготовки тоже нажми установку и закрой Premiere. В настройках этой beta включён приём beta-релизов; для следующих тестовых версий оставь его включённым.

Данные, звуки, варианты, модели и настройки находятся в пользовательской папке Montazhopa3 отдельно от файлов расширения. При обычном обновлении они сохраняются.

## Первая установка или восстановление

1. Полностью закрой Premiere.
2. Распакуй весь `Montazhopa_3.1.0-beta.1.zip` в обычную папку. Не запускай установщик прямо из ZIP.
3. Windows: запусти `INSTALL_WINDOWS.cmd`. macOS: запусти `INSTALL_MAC.command`. Если у `.command` потерялся признак исполняемого файла, открой Terminal, напиши `bash ` с пробелом, перетащи туда этот файл и нажми Enter.
4. Установщик проверит контрольные суммы, сохранит предыдущую панель и установит новую для текущего пользователя.
5. Открой Premiere → Window → Extensions / Extensions (Legacy) → Montazhopa. Конкретное название пункта зависит от версии Premiere и языка.

## Что попробовать первым

- **Звуки → Слушать:** снизу откроется waveform-плеер. Есть позиция, громкость, pitch, reverse. Настройки меняют предпрослушивание; чтобы вставить изменённый звук, сначала создай WAV кнопкой `WAV ↗`, затем вставь полученный ассет. Для экспорта нужен FFmpeg; pitch дополнительно требует фильтр rubberband.
- **Инструменты → Папки под наблюдением:** сохрани проект, добавь папку, выбери подпапки и импорт существующих файлов. Файлы импортируются только пока панель открыта. История раздельная для проектов, ошибки повторяются с задержкой. Поддерживается до 10000 найденных файлов за проход и глубина до 8 папок.
- **Инструменты → Убрать тишину:** выбери исходное видео/аудио, найди речь, проверь интервалы, создай XML и импортируй новую секвенцию. Существующий монтаж не режется. Нужны Python и FFmpeg.
- **Субтитры и повторы:** после установки локального AI-движка распознай речь, исправь текст и экспортируй SRT. Похожие дубли — текстовые подсказки; автоматического выбора лучшего исполнения нет.
- **Синхронизация звука:** выбери два WAV/MP3. Получишь сдвиг для ручного совмещения. Сравниваются первые 120 секунд, диапазон ±30 секунд. При слабом совпадении результат помечается как ненадёжный.
- **Мои пресеты Premiere:** сканирование `.prfpset` по именам и показ файла. Пресет импортируется стандартной командой Premiere в панели Effects. Полноценного автоматического переноса параметров из `.prfpset` в этой beta нет.

## Откат и диагностика

Кнопка «Вернуть предыдущую версию» подготавливает возврат и тоже ждёт закрытия Premiere. Если обновление не произошло, проверь `update.log` в папке пользовательских данных:

- Windows: `%APPDATA%\Montazhopa3`
- macOS: `~/Library/Application Support/Montazhopa3`

Вручную восстановить можно при закрытом Premiere: папка предыдущей панели лежит рядом с текущей и заканчивается на `.previous`. Не удаляй папку Montazhopa3 с личными материалами.
